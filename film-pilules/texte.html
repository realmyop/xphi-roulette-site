Fabriqué à partir de mockups/film-pilules/texte.js par node tools/texte-film-pilules.cjs : ne pas corriger ici, corriger texte.js puis relancer l’outil.

Prototype, 34 répliques, 1 878 caractères à l’écran, environ 147 s de parole (à 13 caractères par seconde) pour un film de 3 min 21,5 s. Phi est une machine : pas de genre marqué dans ses répliques. Le N°48 est « il ».

Comment lire :

  • à l’écran : le temps où la réplique est affichée dans la boîte, donc le temps maximal pour la dire ; dite : la durée de parole estimée (les nombres comptés comme ils se disent, 0,3 s de plus par « … »).
  • Le texte est celui de la boîte ; une ligne par ligne de la boîte (la coupure n’est pas une pause imposée).
  • Entre crochets : le jeu. Une fois la voix enregistrée, ce sont ses durées réelles qui fixent le minutage : on calera les plans sur la voix, pas l’inverse.
  • Les silences sont voulus (la nuit, le titre, le doute et le saut, la mort du N°48, le carnet, la fin).
